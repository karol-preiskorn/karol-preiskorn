# 3D Inventory Documentation

Technical documentation for the 3D Inventory system: a spatial inventory application for warehouses and data centers.

The project combines an Angular and Three.js interface with a Node.js/TypeScript API and MongoDB data model. It includes JWT authentication, role-based access control, activity auditing, Swagger/OpenAPI documentation, Docker deployment, automated tests, and Google Cloud deployment.
