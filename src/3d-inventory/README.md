# 3D Inventory System

**3D Inventory** is a full-stack application for creating the spatial and database representation of warehouses and data centers. It connects an interactive visual interface with structured inventory records, access control, and activity auditing.

The system lets a team locate an asset on a floor, identify its model and attributes, record relationships to other devices, and review changes over time.

## What the system provides

- A visual map of floors and equipment
- Structured records for devices and reusable models
- Flexible metadata through an attribute dictionary
- Relationships between devices, models, and floors
- User, role, and permission management
- Authentication through local credentials or Google sign-in
- Activity and login audit trails
- REST API access for integrations and automated workflows
