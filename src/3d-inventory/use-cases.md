# Potential Users and Use Cases

## Data-center operations

Infrastructure and network teams can associate servers, switches, storage, racks, and other equipment with a floor and spatial position. The 3D view helps operators understand placement while the records preserve detailed model and attribute information.

Typical tasks include:

- Locating an asset during maintenance
- Recording a new or moved device
- Identifying the model and configured attributes
- Tracking connections between equipment
- Reviewing recent inventory changes

## Warehouse and facilities management

Warehouse or facilities teams can represent storage floors, zones, equipment, and physical assets. The flexible attribute model allows each device or model to have relevant metadata instead of forcing every asset into the same fields.

Typical tasks include:

- Mapping fixed assets to a location
- Organizing inventory by floor or building area
- Recording responsible equipment types
- Maintaining model templates and reusable attributes
- Searching inventory from structured data

## Administrators and auditors

Super-admin and administrator users can manage accounts, roles, permissions, activity records, textures, and protected backup operations. Audit data makes it possible to review which account performed a change and which values changed.

Typical tasks include:

- Assigning an appropriate role
- Reviewing failed or successful login activity
- Filtering logs by operation, component, date, or user
- Investigating before-and-after values
- Protecting recovery information through controlled backups

## Developers and integrators

The REST API and Swagger/OpenAPI documentation make inventory data available to external tools and automated workflows. Integrators can connect the system to discovery, reporting, deployment, or asset-management processes.

Potential integrations include:

- Importing discovered devices
- Exporting inventory reports
- Synchronizing model and attribute definitions
- Automating audit or operational checks
- Building a separate application or dashboard on the API
